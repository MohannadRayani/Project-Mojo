# Tower Defense Game

A tower defense game built with Unity.

## Getting Started

1. Clone this repository
2. Open the project in Unity
3. Navigate to and open the **Main Scene**
4. Build and play!

## Important Notes

⚠️ **Wait until all blocks are loaded before selecting a level.** The game needs time to initialize all assets.

✅ **The game works!** If something seems off or loading is slow, wait a moment—the game is loading in the background.

⚠️ **You will lose on level 3.** 

## How to Play

- Go to the Main Scene to start playing
- Select your level once all blocks have finished loading
- Place towers to defend against enemies
- Manage your resources strategically

## Features

- Multiple tower types with unique attack strategies
- Enemy waves and level progression
- Tower placement and upgrade system
- Dynamic difficulty scaling
